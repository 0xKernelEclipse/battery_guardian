## 2. Capture Methods

### Method A: Host Mock Render (Simulated UI Canvas)
Using the host mock GUI harness, the Flipper canvas bitmap (128x64) can be dumped directly to a monochrome PNG file using the deterministic scenario generator in `tests/platform/test_platform_adapter.c`.
- **Command:** `python scripts/capture_simulated_screens.py`
- **Output Directory:** `assets/screenshots/simulated/`
- **Labeling:** All images generated by this method automatically contain a 1-pixel dotted frame and the text `SIM` in the top-right corner.

### Method B: Physical Hardware Screen Capture (Post-Bench)
Once physical hardware bench validation is completed:
1. Connect Flipper Zero via USB.
2. Launch **qFlipper** on desktop.
3. Open **Screen Stream** and click **Take Screenshot**.
4. Save raw 128x64 PNG images to `assets/screenshots/hardware/`.
